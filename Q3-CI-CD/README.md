# Q3 – CI/CD using GitHub Actions

## Assignment Objective

Apply CI/CD practices to the College ERP application and Git repository by configuring and implementing an automated pipeline to build, test, package, and deploy the application.

---

# CI/CD Tool

**GitHub Actions**

GitHub Actions was selected to implement the automated CI/CD pipeline.
