XP practical: incremental development and testing.

Demo credentials: student@college.edu / Student@123

XP Practices Demonstrated

  • Pair programming: Driver implements the change; Navigator reviews logic and test cases.
  • Small releases: Add password visibility and login validation as small changes.
  • Continuous testing: Check valid and invalid credentials after implementation.
  • Feedback: Show an immediate, understandable message after each login attempt.
  • Simple design: Keep the demonstration small and focused on login behavior.

This is a browser-only academic demonstration. Login credentials are checked in JavaScript and are not secure authentication for a real application.
