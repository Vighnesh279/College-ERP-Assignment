# Level-Up Assignment — Agile Software Development



## Overview



This assignment focuses on applying Scrum, understanding different Agile models, and managing changing requirements through iterative development and customer feedback.



## Question 1 — Implementing Scrum Using Jira



**Objective:** Implement the Scrum framework for a selected software project using Jira.



Activities and evidence:

- Define the Product Owner, Scrum Master, and Development Team.

- Create user stories with acceptance criteria.

- Prepare and prioritize the product backlog.

- Plan a sprint with task assignments and timelines.

- Simulate daily Scrum updates and track progress.

- Conduct a sprint review and retrospective.

- Document the product backlog, sprint backlog, and increment.



Project folder: `Q1-Scrum-Jira/`



## Question 2 — Comparison and Demonstration of Agile Models



**Objective:** Select a software scenario and study three Agile models from the options provided in the question paper.



Activities and evidence:

- Describe the principles and practices of each selected model.

- Prepare a process diagram for each model.

- Demonstrate relevant practical activities.

- Include suitable evidence, such as pair programming, test-first development, feature planning, a Kanban board, or waste identification.

- Compare the models and document the observations.



Project folder: `Q2-Agile-Models/`



## Question 3 — Managing Changing Requirements



**Objective:** Demonstrate how an Agile team responds to changing customer requirements while working with limited resources and continuous feedback.



Activities and evidence:

- Define initial requirements and create a backlog.

- Simulate a change in customer requirements.

- Update and prioritize the backlog based on value, urgency, and available resources.

- Plan an iteration and assign tasks.

- Simulate customer feedback and a review.

- Implement the changes and demonstrate the updated increment.

- Prepare a brief report of the process and results.



Project folder: `Q3-Changing-Requirements/`
